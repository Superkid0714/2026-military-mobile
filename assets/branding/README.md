# 정비온 시각 자산

- `jungbion-vehicle-logo.png`는 Android 앱 아이콘을 다시 만들 때 쓰는 차량 로고 원본이다. `tools/package_jungbion_icon.py`가 화면 밀도별 PNG와 적응형 아이콘을 생성한다.
- `jungbion-guide.png`와 `jungbion-female-guide.png`는 사용 안내에 표시하는 정비 캐릭터다.
- `jungbion-worker-body.png`와 `jungbion-worker-arm.png`는 대기 화면에 쓰는 몸통·공구 레이어다. 레이어는 같은 캔버스에 맞춰 정렬되어 있다.
