# 2026-11-13 화면·사진 점검 정리와 공개 전 검증

이 문서는 현재 변경본을 다시 실행해 확인한 결과다. 날짜는 작업 채팅의 사용자 시간대를 따른다. 이전 날짜의 QA 결과를 현재 결과로 재사용하지 않았다.

## 화면 변경

- 홈을 관리 차량·점검 필요·이달 정비 기록·비용, AI 상태 분포, 정비 일정·추이 중심으로 정리했다.
- 홈의 AI 상태 그래프에 미분석을 포함하고, 기본 차량 목록과 조회 범위·점수 자릿수·정렬 기준을 맞췄다.
- 차량 목록에서 전체·낮음·관찰·높음·미분석을 선택하며 각 상태의 차량 대수를 확인한다.
- 기록은 정비 기록·운행 기록 두 탭으로 구분했다. 이번 달 조회는 별도 탭 대신 공통 기간 필터로 제공한다.
- 기간 필터는 전체·이번 달·최근 3개월·시작일/종료일 직접 선택을 지원한다. 시작일과 종료일을 모두 포함한다.
- 운행 기록은 차량번호·차종·출고연도·누적 거리·누적 시간·누적 유류를 표시한다. 누적값을 기간 증가량으로 간주하지 않는다.
- 백업·자료 가져오기와 현장 요청은 일반 메뉴·사용 안내에서 제외했다. 내부 저장·이력·백업 호환성은 유지한다.
- 앱 이름, 한국어 안내, 등록 양식, 화면 뒤로 이동과 큰 글자 레이아웃을 정리했다.

## 사진 점검

### 실제 촬영

전면 외관·엔진룸 모두 전체 사진을 촬영한 뒤 위치를 눌러 번호 마크를 추가한다. 부위나 점검 상태를 선택해야 저장할 수 있는 제약은 제거했다.

- 사진당 최대 100개 마크. 마크를 다시 누르면 삭제한다.
- 마지막 마크 취소·전체 삭제, 메모·녹음 첨부를 지원한다.
- 마크가 없어도 사진·메모를 저장할 수 있다.
- 좌표는 원본 표시 영역에 대한 0~1 비율로 저장하며 범위 밖·비유한 좌표·과다 개수는 거부한다.
- 사진·마크·메모는 재조회와 백업·복원에서 유지한다.
- 과거 부위별 기록의 좌표도 번호 마크로 표시한다. 기존 기록 형식은 읽을 수 있다.
- 사진 로딩 오류 메시지가 로딩 표시로 덮이지 않도록 수정했다.

### AI 검사 시연

전면·엔진룸 이미지에서 디지털 트윈 화면을 열면 부위를 순서대로 스캔한다. 정상 항목부터 결과가 쌓이고 전조등 또는 배터리의 이상 의심 결과가 표시된다. 일시정지·재개·확인 필요 표시·결과 저장·직접 촬영 연결을 제공한다.

이 경로는 실제 모델 추론과 별개인 고정 시나리오다. 저장된 기록의 `mode`에 `디지털 트윈 시연`을 남긴다. 실제 촬영 후 마크 저장은 `전체 사진 점검`으로 구분한다. 생성 차량 이미지는 실장비 사진이나 특정 차종의 정비 배치도가 아니다.

## 이번 환경의 검증 결과

| 검사 | 결과 |

| 전체 Flutter 테스트 | **305개 통과** — `flutter test --no-pub` 재실행 |

| 화면 비교 | 홈·차량 필터의 의도한 변경을 확인하고 해당 macOS ARM64 기준 이미지를 갱신한 뒤 전체 테스트 통과 |
| 사진 저장·호환성 | 전면·엔진룸 마크 추가·삭제·저장·재조회, 구형 기록, 백업 복원 검사 포함 |

전체 테스트의 첫 실행에서는 이전 화면 기준 이미지 4건과 사진 로딩 대기 2건이 실패했다. 의도한 화면 변경을 시각적으로 확인해 기준을 갱신하고, 사진 표시의 로딩 오류 처리를 수정한 다음 **전체 305개를 다시 실행해 통과**했다.

Dart 정보 안내는 `model_execution.dart`의 `avoid_print`와 기기 검사·테스트 코드의 중괄호 권고 두 건이다. Flutter 분석 서버 실패와 대체 Dart 분석 결과를 구분한다.

## 확인하지 않은 범위

- Android 계측 테스트 소스는 최신 안내 단계에 맞췄지만 계측 테스트 자체를 이번 공개 준비에서 다시 실행하지 않았다.
- 마지막 전체 테스트 중 사진 로딩 처리 수정 이후 release APK를 최종 재빌드하되, 그 수정만을 대상으로 한 태블릿 촬영·전 기능 실사용 재검증은 별개다.
- 모델의 실제 고장 판별 정확도·최소 RAM·모든 기종 호환성을 이번 UI 테스트로 검증한 것은 아니다.
- 화면 예시·생성 이미지·합성 데이터 외에 실제 사진·원본 업무 자료·로컬 색인·모델 가중치·APK·DB·로그는 커밋하지 않는다.
