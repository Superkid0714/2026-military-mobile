# 온보딩과 캐릭터 대기 안내

버전 0.8.0+13.

처음 앱을 열면 정비온 소개, 기기 내 책자 검색, 기록·분석·점검 순서의 3단계 안내를 보여준다. 다음/이전/건너뛰기를 제공하고, 완료 여부는 기기 DB의 `app_metadata.onboarding_v1`에 기록한다. 다시 실행하면 반복하지 않으며 초기 설정의 ‘정비온 사용 안내’에서 다시 열 수 있다. 백업은 업무 데이터만 옮기므로 기기의 안내 완료 설정은 백업 복원으로 지우지 않는다.

사용자가 지정한 군용 헬멧·스패너 정비병 이미지는 로컬 PNG로 묶어 네트워크 없이 표시한다. 대기 중 캐릭터가 천천히 위아래로 움직이고 살짝 기울어진다. 앱 준비, 챗봇 답변, 책자 검색, 자료 백업·복원, 기록 저장·분석 갱신에 ‘정비 중…’과 실제 작업 설명을 표시한다. 모델·책자 묶음 설치 중에는 앱 위에 대기 화면을 띄워 중복 작업을 막는다.

일반 작업의 캐릭터는 약 250ms 후 표시해 짧은 작업에서 번쩍이지 않도록 한다. 작업이 끝나면 즉시 제거하며 보여주기 위한 가짜 지연·가짜 진행률은 없다. 기기의 애니메이션 줄이기 설정에서는 캐릭터 움직임을 중지한다. 화면을 떠나면 타이머와 애니메이션을 해제한다.

전체 자동 검사 247개 통과. 안내 저장·재시작 기억, 600×800 및 1280×800 큰 글자 3단계, 건너뛰기, 캐릭터 움직임·정지·해제를 포함한다. 기존 56개 화면 조건 검사도 포함된다. 정적 분석과 실기기 결과는 비공개 QA 기록을 따른다.
