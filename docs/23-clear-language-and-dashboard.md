# 쉬운 화면 문구와 기록 중심 종합현황

버전 0.9.0+15. 화면에 표시하는 RAG·임베딩·키워드·Vision·LLM 등은 책자 찾기, 질문 뜻과 입력한 말 살펴보기, 사진 속 물체 찾기, 원문 문장 정리처럼 기능을 설명하는 말로 바꿨다. 부품 개념은 부품 이름, 정비 계통은 정비 종류, 선도래 순서는 거리와 날짜 중 무엇이 먼저인지 설명한다. 내부 검색 방식과 계산 결과, 원본 책자 문장은 변경하지 않는다.

상단의 ‘로컬 실행 중’, ‘현장 모드’와 하단의 저장 상태 패널을 제거했다. 날짜와 작은 앱 버전 표시는 남긴다. 종합현황은 조회 차량, 지금 점검할 항목, 최근 30일 정비, 이번 달 정비비를 먼저 표시하고 점검 목록·최근 6개월 그래프·최근 정비·차량 상태를 연결한다.

운용 예시는 화면에 고정 숫자를 쓰지 않고 기기에 저장한다. 별도의 `MOCK-OPS-` 그룹 12대, 월별/현재 운용 84건, 정비 92건, 점검 주기 12건이다. 모든 예시 행은 생성 자료로 표시하고 실제 실적이라고 주장하지 않는다. 점검 간격은 시연 가정이며 제조사 기준이 아니다. 예측 점수는 기존 모델이 기록에서 계산하며 임의로 지정하지 않는다. 날짜는 최초 추가 시 기기 날짜를 기준으로 작성하고 반복 실행에서는 기존 예시를 덮어쓰거나 중복 추가하지 않는다.

종합현황에서 운용 예시/등록 차량을 선택한다. 목록·기록·분석의 집계도 선택 그룹을 따르며 서로 합산하지 않는다. 이미 입력한 등록 차량과 이력, 책자 자료는 유지한다. 새 앱 시작에서 한 번 추가하며 기록 관리 화면에서도 추가할 수 있다.

아이콘은 사람 대신 흰색 배경의 올리브 군용 차량과 민트색 스패너로 변경했다. 안내와 대기 캐릭터는 유지한다.

전체 자동 검사 250개 통과. 29개 화면 기준을 전후 비교하고 큰 글자/가로·세로 56개 조건도 검사했다. 원본 자료와 실기기 상세 결과는 비공개 QA 기록을 따른다.
