# UI 간격과 글자 잘림 점검

대상 버전: 0.7.1+9. 기존 업무 자료를 유지한 UI 수정이다.

## 수정

- 차량 목록·정비 기록 표: 고정된 전체 폭으로 인해 큰 글자에서 열 제목이 넘치는 문제를 수정했다. 열의 실제 내용에 맞춰 폭을 확보하고 필요한 경우 가로 스크롤한다. 제목은 한 줄을 유지한다.
- 공통 표: 고정 최대 행 높이를 해제해 큰 글자와 여러 줄 내용이 행 밖으로 잘리지 않도록 했다. 제목 행도 글자 크기에 맞춰 높이를 확보한다.
- 촬영 대상 카드: 고정 높이를 최소 높이로 바꿔, 좁은 화면에서 설명이 여러 줄이 되면 내용에 맞춰 높이가 늘어나게 했다. 일반 크기에서 불필요한 빈 공간을 추가하지 않는다.

## 검사 범위

14개 화면을 600×800/글자 1.6배, 800×1280/1.3배, 1280×800/1배 및 1.6배의 56가지 조건에서 렌더링하고 아래쪽까지 스크롤하며 레이아웃 예외를 확인한다. 책자 화면은 긴 시험용 제목 7개를 사용하며 원본 자료를 공개 테스트에 넣지 않는다. 입력창·대화상자·그림 확대는 기존 사용성 및 그림 UI 검사도 함께 실행한다.

56개 화면 조건과 사용성 10개 검사는 수정 후 통과했다. 56장 화면을 살펴보고 표의 폭·행 높이로 달라진 기준 이미지 3개(차량 목록, 입력 이력, AI 분석 이력)를 이전 이미지와 비교한 뒤 반영했다. 이 검사는 모든 가능한 데이터·화면 크기를 보장하지 않으며, 비공개 실기기 결과는 로컬 QA 보고서에 보관한다.

최종 전체 자동 검사 243개 통과, 정적 분석 오류·경고 없음(기존 info 3개). 실제 태블릿의 오프라인 분석·예측 이력 화면과 챗봇·그림 확대 검사도 통과했다. 기존 업무 데이터는 보존됐으며 UI 검사가 저장한 질문 이력만 추가됐다.
