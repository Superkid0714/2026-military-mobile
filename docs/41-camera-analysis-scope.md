# 카메라 분석 적용 범위

2026-11-12 작업 기준.

## 현재 동작

렉스턴 스포츠 전면 사진 점검에서 '화면 분석 켜기'를 선택하면 카메라 장면을 순차 촬영해 기기에 설치된 전면 부위 모델로 분석한다. 각 분석이 끝난 뒤 1.8초 후 다음 분석을 요청한다. 영상 프레임마다 추적하는 YOLO 기능은 아니다.

최근 분석 장면에 위치 후보 박스를 표시한다. 박스 또는 부위 버튼을 누르면 옆 차량 상태도에서 같은 부위를 선택한다. 분석 후보를 점검 완료 상태로 자동 저장하지 않는다. 촬영 및 기록, 대상 변경, 미리보기 고정 시 진행 중 분석이 끝난 뒤 카메라 작업을 이어간다. 앱이 비활성화되면 반복 분석을 멈춘다. 분석용 임시 촬영 파일은 처리가 끝나면 삭제한다.

엔진룸은 부위 위치를 직접 표시한다. 자동 품번 판별, 고장 확정, 3D 디지털 트윈은 지원하지 않는다.

## 부대 운용 시나리오와의 차이

- 차량 현황, 교범 검색, 사진 점검, 정비 기록은 현장 흐름의 기반이다.
- 실제 DELIS 이력과 운행 지형 자료 연동, 가동률의 부대 전체 실시간 집계는 별도 연결이 필요하다.
- 사고·고장 위험 지도에는 위치 자료와 폐쇄망에서 사용할 지도 및 분석 기능이 필요하다.
- 엔진룸 자동 인식과 품번 매칭에는 해당 부품 모델, 품번 대조 자료, 실제 차량 검증이 필요하다.
- 부속 청구 및 태블릿 간 동기화, 피드백 전송은 별도 업무 시스템 연동이 필요하다. 오프라인 기록 후 연결 복구 시 전송하는 구조가 적합하다.
- 수집된 피드백은 검토와 재학습·검증을 거쳐 모델에 반영해야 한다.

## 최초 적용 검사

후속 점수 표시와 현장 요청 및 최신 검사는 [현장 시나리오 검사](42-field-scenario-qa-2026-11-12.md)를 따른다.

- 초기 사진 점검 테스트 4개 통과. 카메라 분석 시작·표시·중지, 기존 사진 보존, 자동 기록 미생성 및 엔진룸 자동 분석 미실행 포함.
- 수정 Dart 파일 3개의 flutter analyze 통과.
- 실제 차량에서 부위 정확도·처리 속도, 장시간 반복 동작은 이번 자동 테스트의 검증 범위가 아니다.
