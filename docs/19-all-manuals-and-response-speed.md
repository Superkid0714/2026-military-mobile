# 전체 책자와 빠른 오프라인 답변

## 반영 범위

사용자 요청에 따라 1번 운용실적, 2번 정비실적·수리부속 자료는 이번 책자 묶음에서 제외한다. 나머지 7권의 물리 페이지 5,728쪽을 원본 페이지 이미지와 함께 수록한다. 텍스트 검색 대상은 5,466쪽이며, 빈 페이지나 검색 문자가 부족한 도면도 `책자 검색 · RAG → 책자 직접 보기`에서 책자와 PDF 페이지 번호로 열 수 있다. 이전/다음 페이지와 그림 확대를 지원한다.

배선도는 원본 PDF의 문자 매핑이 깨져 로컬 Apple Vision OCR로 복구했다. OCR은 페이지를 찾는 데 사용하고, 인식한 핀번호·배선색을 검증된 정비 지시로 자동 인용하지 않는다. 해당 질문에는 원본 도면을 확인하도록 안내한다. 원본 PDF는 수정하지 않으며 자료·색인·페이지 이미지는 공개 저장소에 포함하지 않는다.

## 응답 방식

일반 챗봇과 검색 화면은 질문에 맞는 원문 문장을 고르고 쉬운 설명과 출처를 표시한다. 매 질문마다 선택형 로컬 언어모델을 실행하는 대기 시간을 없앴다. 이 모드는 자유로운 문장 생성 모델의 답변을 의미하지 않는다. 질문 관련 근거가 없으면 답변을 만들지 않는다. 정비 주기 수치는 등록된 기준을 따르고 OCR 수치를 대신 사용하지 않는다.

의미 검색용 임베딩 모델과 차량 예측·정비 분류 모델은 계속 기기 내부에서 실행한다. 언어모델의 선택적 실행 경로도 진단용으로 유지한다. 책자 묶음은 설치 시 전체 해시·DB·이미지 검사를 수행하고 원자적으로 교체한다. 임베딩 시작 시에는 설치된 대용량 책자 전체를 다시 해시하지 않아 초기 대기를 줄인다.

## 검증 기록

전체 책자 검색의 검토된 질문 20개는 PC 검사에서 모두 지정한 근거를 상위 5개 안에서 찾았다. 이는 모든 가능한 질문의 정확도를 뜻하지 않는다. 오프라인 태블릿 챗봇 9개 검사도 통과했다. 같은 두 질문의 답변 시간은 이전 16,663/14,663ms에서 이번 2,852/2,041ms로 줄었다. 두 질문의 실측이며 모든 질문의 응답 시간 보장은 아니다. 신규 OCR 질문의 참고 결과 하위 순위가 PC와 다른 사례가 있어 첫 결과와 검토된 정답 포함 여부를 별도로 비교하고, 기존 16개 질문은 전체 순위를 비교한다. 자세한 실기기 결과는 비공개 QA 기록에 남긴다. 원본과 색인이 포함되지 않은 APK만 다른 기기에 설치하면 책자 묶음 반입이 추가로 필요하다.

최종 태블릿 검색은 20개 모두 검토된 정답을 찾았고, 7권의 첫·마지막 페이지 14개 조회와 일반 앱의 배선도 이전/다음 이동도 통과했다. 기존 업무 DB의 모든 테이블 행수·내용 해시는 검사 전후 같았다. PC와 전체 참고 순위가 같은 질문은 18/20이며 신규 OCR 2개의 하위 순위 차이는 남아 있다.
