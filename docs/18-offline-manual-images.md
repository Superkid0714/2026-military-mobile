# 오프라인 책자 페이지 이미지

앱 0.6.0부터 정비 도우미의 답변에 인용된 책자 페이지를 미리보기로 표시한다. 실제 정비 책자 한 페이지를 이미지로 저장하므로 사진·그림·화살표·주변 설명을 함께 확인할 수 있다.

## 사용 방법

1. 정비 도우미에서 부품이나 작업을 질문한다.
2. 답변 아래의 책자 페이지 미리보기를 누른다.
3. 두 손가락 또는 + / − 버튼으로 확대·축소하고, 드래그해서 위치를 옮긴다.
4. ‘원래 크기’로 돌아가거나 ‘그림 닫기’를 누른다. 글로 된 원문 출처도 계속 열 수 있다.

답변에서 실제로 인용한 페이지 중 최대 2개를 표시한다. 검색 결과에 있다는 이유만으로 관계없는 페이지의 그림을 붙이지 않는다. 문서명과 PDF 페이지 번호를 함께 표시한다.

## 오프라인 자료

현재 품질 검사를 통과한 6개 책자의 검색 가능 4,700쪽 전체에 페이지 이미지를 준비했다. 페이지당 긴 변 1,600픽셀, JPEG 품질 70의 미리보기다. 이미지 포함 검색 묶음은 약 502MiB이며 설치된 검색 DB는 약 597MiB다. 실제 원본 PDF와 같은 해상도의 벡터 확대를 제공하는 것은 아니다.

앱 0.6.0과 이미지 포함 `.mrag` 묶음을 처음 한 번 반입하면 이후 질문·그림 열기·확대에 인터넷이 필요하지 않다. 기존 글 전용 묶음도 계속 사용할 수 있다. 그림이 없거나 손상되면 글 답변과 원문 조회를 유지한다. 새 기기에는 앱뿐 아니라 이미지 포함 검색 묶음도 반입해야 한다.

원본 책자·이미지·모델·검색 묶음은 비공개 자료로 관리하며 APK 소스나 공개 저장소에 넣지 않는다. 실제 운용·정비 실적 PDF와 검색에서 제외된 문서는 이미지 검색 자료에 포함하지 않았다.

## 페이지 연결과 자원 사용

기존 검색 DB의 문서·페이지·벡터는 변경하지 않고 별도 `page_images` 테이블을 추가한다. 문서 ID, PDF 페이지, 원본 문서 SHA-256, 파일명이 모두 맞는 이미지에만 접근한다. 묶음을 반입할 때 파일 해시·DB 무결성·페이지 수·이미지 크기를 검증하고 임시 폴더 검증이 완료된 후 활성 자료를 교체한다.

필요한 인용 페이지를 백그라운드에서 읽고, 미리보기는 축소 디코딩한다. 이미지 전체를 한 번에 메모리에 올리지 않는다. 페이지당 2MiB와 최대 1,800픽셀 범위를 제한한다. 설치 파일은 최대 1,280MiB, 검색 DB는 최대 1,024MiB, 전체 압축 해제 데이터는 최대 1,536MiB로 제한한다. 파일 선택 반입도 같은 상한을 따른다.

## 재생성

기존 벡터를 재학습하지 않고 원본 PDF와 기존 검색 묶음을 확인한 뒤 페이지 이미지를 추가한다.

```sh
.tools/rag-env/bin/python tools/build_manual_page_images.py \
  --base private/manual-rag-v2/bundle \
  --inputs private/pdf-intake-2026-11-04/inputs.json \
  --output private/manual-rag-images-v1
```

출력 경로는 `private/` 안으로 제한한다. 원본 PDF 해시가 기존 검색 DB와 다르거나 이미지가 누락되면 완료 묶음을 만들지 않는다. 기존 출력 폴더에 덮어쓰지 않으므로 새 출력 경로를 사용한다.
