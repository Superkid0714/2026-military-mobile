# 정비온 0.9.4

## 기능

- 종합 현황에서 다음 점검과 차량별 정비 기록을 열 수 있다. 정비 분석은 계통별·월별 차트와 이전 예측을 보여 준다.
- 정비 질문은 차량 기록과 반입한 책자를 바탕으로 답한다. 책자 검색 결과의 페이지를 열고 그림을 확대할 수 있다.
- 차량 상태 지도에서 전면 외관과 엔진룸을 선택한다. 전면은 선택 모델이 제안한 위치를 사람이 확인한다. 엔진룸은 사진에 네 부위의 위치를 직접 표시하고 상태를 저장한다.
- 처음 열 때 사용 안내를 보여 준다. 카메라와 검색처럼 시간이 걸리는 작업은 진행 상태를 화면에 표시한다.

## 빌드와 확인 범위

- 버전 이름은 `0.9.4`, Android 버전 코드는 `19`다. 출시 빌드에서 ONNX Runtime이 네이티브로 호출하는 Java 클래스는 최적화 과정에서 보존한다.
- 개발 환경의 APK 용량은 디버그판 약 171MB, 출시 빌드 약 95MB였다. 앱은 시작 시 기록을 한 번 읽고, 사진 목록은 작은 미리보기로 표시한다.
- 2026-11-09 작업에서 Flutter 테스트 263개가 통과했다. 오프라인 태블릿에서 정비 분석과 예측 이력, 챗봇과 책자, 카메라 미리보기와 저장 사진을 확인했다. 최종 APK에서는 뜻 기반 책자 검색과 저장된 엔진룸 기록을 재확인했다.
- 예측 동작은 합성 기록으로 확인했다. 차량 전면 인식의 현장 정확도는 추가 확인이 필요하다. 책자 원문·색인, 선택 모델 및 APK는 공개 소스 범위에서 제외한다.
