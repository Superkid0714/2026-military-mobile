# 오프라인 정비 도우미

앱 0.5.0부터 `정비 도우미` 메뉴에서 차량을 선택하고 질문할 수 있다. `/chat`은 별도 대화 화면이며 기존 `AI 정비지원`과 책자 검색 화면도 유지한다.

## 사용하는 정보

- 선택 차량의 확인된 정비 주기와 점검 순서
- 해당 차량의 과거 정비 이력: 미래 날짜와 다른 차량 기록은 제외, 최대 5건
- 기기에 반입한 책자 검색 자료: 최대 5개 출처
- 기기에 설치한 요약 모델: 사용할 수 있을 때 근거 문장을 선택하며 서버를 호출하지 않음

예: `무엇부터 점검해야 해?`, `최근 정비 이력을 알려줘`, `브레이크 패드 점검 시 주의사항은?`. 짧은 `그럼 주의사항은?` 같은 질문에는 직전 주제를 이어서 검색한다. 다른 부품을 명시한 새 질문에는 이전 부품을 붙이지 않는다. 차량을 바꾸거나 새 대화를 누르면 대화 맥락을 비운다.

## 답변의 구성

차량 기록을 바탕으로 한 안내, 점검 순서와 이유, 관련 원문 인용, 책자 출처, 관련 정비 이력을 함께 표시한다. 출처를 누르면 원문을 읽을 수 있다. 챗봇은 정비 기록·주기·모델 점수를 수정하거나 자동으로 교환을 지시하지 않는다.

기본 모델은 가상 데이터 학습 모델이다. 점수는 실제 고장 확률로 해석하지 않으며 선택 차량의 기존 예측 가용성 정책을 그대로 따른다. 현재 검색 묶음은 2023 렉스턴 참고 자료이므로 다른 차종에는 적용 답변을 만들지 않는다. 같은 차종이라도 실제 연식·사양 적용 여부는 원문과 확인된 차량별 규칙으로 확인한다.

## 쉬운 설명과 질문 적합성 (0.5.1)

점검 순서 질문에는 확인할 항목·등록 기준·반복 수리 횟수·다음 확인 행동을 먼저 설명한다. 숫자 설명은 확인된 교환 기준과 운용값 또는 저장된 모델 입력에서 가져오며 새 수치를 추정하지 않는다. 이력 질문에는 최근 날짜와 작업을 최대 3건으로 요약하고 전체 최대 5건은 펼쳐서 확인한다. 이런 차량 기록 질문에는 불필요한 책자 검색을 하지 않는다.

제동·타이어·조향 질문은 새시 책자, 엔진·필터 질문은 엔진 책자를 우선 검색한다. 엔진 브레이크와 여러 계통을 함께 묻는 경우는 구분한다. 우선 자료가 없으면 전체 검색으로 돌아간다. ‘주의사항’ 표현은 검색할 때 ‘주의’로 정리하며, 주의·손상·금지 등 관련 표현이 없는 일반 현상 설명은 주의사항 답변으로 인용하지 않는다. 이 검사는 표현에 기반한 제한된 검사이며 모든 질문의 의미 적합성을 보장하지 않는다.

‘쉽게 설명하면’에서는 탈거→분리, 장착→설치 및 문장 종결의 고정 변환만 사용한다. 원문 인용과 수치·부정 표현은 별도로 보관하며 ‘책자 표현 그대로 보기’와 출처로 확인한다. 탈거·장착·누유·마모·고무 부트·O-링 등 등장한 용어를 풀이하고, “탈거가 무슨 뜻이야?” 같은 질문에는 용어 뜻을 바로 설명한다. PDF 줄바꿈으로 갈라진 일부 단어는 표시에서만 정리하며 같은 뜻의 인용 문장은 중복 표시하지 않는다. 관련 책자를 찾았더라도 직접 답할 문장이 없으면 필요한 부품명과 작업을 추가로 묻는다.

## 통신 없이 동작하는 조건

앱과 책자 검색 묶음이 기기에 준비되어 있어야 한다. 처음 자료를 넣는 작업은 PC·USB로 할 수 있다. 이후 질문 처리에 인터넷·API 키·외부 서버가 필요하지 않다. 기존 `ManualRag`의 키워드·벡터 검색과 `LocalSummary`의 기기 내 모델을 사용한다.

요약 모델이 없거나 메모리가 부족하면 원문의 관련된 완전한 문장을 그대로 인용하고 출처를 보여준다. 안전하게 추출할 수 없는 수치·주기는 답변 문장으로 재구성하지 않고 원문과 등록 기준에서 확인한다. 검색 자료가 없거나 근거를 찾지 못하면 선택 차량의 기록·기준은 안내하되 원인을 지어내지 않고 추가 정보를 요청한다. 일반 상식 자유 대화를 생성하는 범용 챗봇은 아니다.

질문은 차량별 로컬 질문 이력으로 저장한다. 답변과 대화 맥락은 화면 세션에만 보관하며 최대 20개 답변을 유지한다. 전송 중에는 중복 전송·차량 전환을 막는다. 질문 기록 저장 실패가 답변 표시까지 막지는 않는다.

## 검증

- `test/offline_assistant_test.dart`: 차량 격리, 후속 질문, 검색·요약 실패, 근거 문장 검증, 미지원 차종, 입력 제한
- `test/offline_chat_ui_test.dart`: 질문 전송·로컬 저장, 원문 열기, 진행 상태·차량 전환, 작은 화면·큰 글자
- `offlineChatDeviceProbe`: 기기에 설치된 실제 자료로 답변·출처·후속 질문·점검 순서와 차량 격리 확인. 업무 DB를 열지 않는 별도 메모리 시나리오 사용
- `run_manual_ui_qa.py --mode chat`: 일반 앱 화면에서 질문 전송·출처 열기. 이 검사는 질문 이력만 저장하며 차량·운용·정비 기록을 수정하지 않음

전체 및 기기 검사 결과는 해당 실행의 비공개 QA 보고서를 확인한다. 과거 실행 성공을 현재 실행 성공으로 대신하지 않는다.

책자 사진·그림 미리보기와 확대는 [오프라인 페이지 이미지 안내](18-offline-manual-images.md)를 참고한다.
