# 여성 안내 캐릭터와 자연스러운 작업 동작

버전 0.8.1+14. 온보딩은 체크리스트를 든 여성 정비병이 안내하고, 대기는 기존 남성 정비병이 작업하도록 구분한다. 두 캐릭터는 같은 올리브·민트 3D 스타일을 사용하며 확정된 앱 아이콘은 유지한다.

이전 대기의 전신 상하 이동과 회전을 제거했다. 고정 몸통과 손·소매·스패너를 분리한 로컬 PNG를 같은 캔버스 정렬로 겹치고, 팔 부착점을 축으로 도구를 조금 조였다가 복귀한다. 2.8초 주기에 휴식 구간과 부드러운 가감속을 넣고 반복 경계에서 각도가 튀지 않게 했다. 작업 완료 시 바로 사라지는 동작과 애니메이션 줄이기 설정은 유지한다.

전체 자동 검사 249개 통과. 큰 글자 온보딩, 몸 위치 고정, 팔 움직임, 정지 설정, 휴식 구간·반복 경계의 연속성, 20개 동작 프레임 렌더링을 포함한다. 이미지 원본과 최종 프롬프트 설명은 assets/branding/README.md에 기록한다. 로컬 시각·실기기 결과는 비공개 QA 기록을 따른다.
