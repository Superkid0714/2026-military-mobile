# 현장 시나리오 적용 및 검사

기준일: 2026-11-12. 이 문서는 이번 실행에서 확인한 결과와 남은 범위를 구분한다. 사진, 원문 교범 인용과 실기기 상세 로그는 공개하지 않고 private/current-scenario-qa/에 보관한다.

## 추가한 흐름

- 사진 점검 → 부위 선택 → 부속 요청 작성: 차량·부품 이름을 이어받고 확인한 품번, 수량, 사유를 저장한다. 품번이 없으면 '확인 필요'로 표시한다.
- 사진 점검 → 인식 오류 제보: 차량과 부품, 오류 내용을 저장한다.
- 더 보기 → 현장 요청: 요청과 제보를 조회하고 처리 완료 또는 다시 확인 상태로 변경한다. 잘못 작성한 요청은 확인 후 삭제한다.
- 요청과 제보는 기기에 저장되며, 기존 기록 백업과 복원에 포함한다. 자동 전송이나 자동 재학습이 이뤄졌다고 표시하지 않는다.
- 카메라의 최근 분석 장면을 미리보기 영역 안에 표시하고, 사진의 원래 비율에 맞게 인식 박스를 배치한다. 박스 또는 부품 선택 버튼을 누르면 옆 부위 안내도에 연결된다.
- 실제 전면 모델이 반환한 점수를 '인식 점수 87.5%'와 같은 형식으로 표시한다. 미인식은 '미인식', 장면에 후보가 없으면 '인식된 부품이 없습니다'로 안내한다. 모델 점수가 누락되면 임의의 숫자 대신 '점수 없음'을 표시한다.
- 인식 점수는 모델 출력 점수이며 검증된 정확도나 고장 확률이 아니다. 모델의 후보 표시 기준은 0.25 이상이고, 낮은 점수의 후보도 사람의 확인이 필요하다.
- 분석 중 촬영을 요청하면 분석 종료 후 사진을 촬영한다. 동시에 카메라 촬영 두 건을 실행하지 않는다.

## 현재 실행한 검사

- Flutter analyze: 오류·경고 없음. 기존 정보성 권고 3개(디버그 출력 1개, 중괄호 스타일 2개)는 남아 있다. 한글 경로에서 도구 오류가 있어 같은 소스·자산·검사 도구를 ASCII 임시 경로에 복사해 검사했다.
- 전체 Flutter 테스트: 281개 통과. 저장·백업, 예측·분류, 검색·응답, 주요 화면 및 4가지 화면 크기·글자 배율의 배치 검사 포함.
- 모델 점수의 범위·결측 처리, 박스 위치와 사진 비율, 부위 선택 전달 및 분석 중 촬영 대기 검증 포함.
- SM-T735N 태블릿에서 통신을 차단한 진단용 빌드로 예측 3,600건과 분류 861건을 기준 출력과 비교해 통과. 이는 실행 결과 일치 검사이며 실제 부대 고장 예측 정확도의 검증이 아니다.
- 같은 기기의 오프라인 챗봇 진단 9개 통과. 교범 근거 검색, 주의사항, 후속 질문, 차량별 정보 분리, 관련 없는 질문 처리와 쉬운 용어 설명 포함.
- 사용용 APK에서 카메라 분석·정지·미리보기 고정·재개·촬영·확인 어려움 상태 저장 확인. 일반 테스트 대상을 사용했으며 실제 차량 부위 인식 정확도 검사는 아니다.
- 사용용 APK의 패키지 권한 검사 통과: CAMERA 및 앱 내부 동적 수신기 권한만 선언, INTERNET 권한 없음, allowBackup=false.
- 최종 0.9.20 사용용 APK에서 접근성 버튼 동작으로 오프라인 실기기 25단계 통과. 요청·제보의 재실행/버전 업데이트 후 보존, 처리 상태, 삭제, 카메라 반복 분석, 명시적인 미인식, 점수 설명, 분석 중지 및 미리보기 고정·재개를 확인했다. 테스트 요청·제보는 삭제했다.
- 오프라인 검사 후 통신 설정과 임시 화면 유지 설정을 원래 값으로 복원했다.
- 실제 차량의 부품을 촬영한 양성 장면에서 점수가 표시되는지는 이번 실기기 검증 범위가 아니다. 점수 전달·유효성·결측 표시는 자동 테스트로 검사했고, 실기기는 차량이 아닌 테스트 대상으로 미인식을 확인했다.
- 사용용 APK를 대상으로 기존 진단 도구를 실행한 첫 시도는 Kotlin 테스트 의존성 부재로 중단됐다. 진단용 APK를 별도 설치해 검사를 수행했다. 사용용 APK의 화면 검사는 별도로 수행하며 진단 빌드 결과와 구분한다.

## 추가 연동과 검증이 필요한 범위

- 실제 DELIS 이력·지형 자료, 전체 부대 차량의 실시간 집계, 배차 승인 권한 및 기록.
- GPS 위험지역 자료와 폐쇄망에서 사용할 지도.
- 엔진룸 자동 부품 인식 모델과 차량 사양별 품번 대조 자료 및 실제 차량 평가.
- 부속 청구 시스템으로의 제출, 태블릿 간 동기화, 피드백 전송과 승인된 재학습 절차.
- 실제 차량에서 반복 촬영·조명·각도별 정확도, 장시간 분석 시 발열·배터리 측정.
- 현재 부위 그림은 2D 상태 안내도다. 3D 디지털 트윈이나 연속 영상 추적 기능으로 표현하지 않는다.
